## 1. Goal
The web app has its real foundation — HeroUI v3 themed with our tokens (dark + light), Sarabun, TanStack Query, a typed fetch wrapper, MSW mocks, Vitest + Playwright — and **one read-only screen (`/pos/menu`) built on all of it with mock data**. That screen is the HeroUI spike DR-002 asked for: if HeroUI fights us, we find out here, not in Sprint 2.

## 2. Scope
### In
- **Packages** exactly as §7 (from repo root: `pnpm --filter @bar/frontend add …`).
- **Fonts / language:** Sarabun via `next/font/google` (weights 400/500/600/700, `thai` + `latin` subsets) replaces Geist; `<html lang="th">`. Update `metadata` title to "The Loft Bar".
- **Theme:** `globals.css` — Tailwind v4 + `@heroui/styles`; design-system tokens as CSS variables (dark on `:root, .dark`, light on `.light`), exposed through `@theme` (`bg-bg`, `bg-surface`, `text-text-primary`, `text-accent-text`, …) and mapped onto HeroUI's theme variables. `next-themes` provider (`attribute="class"`, `defaultTheme="dark"`, `enableSystem`). `ThemeToggle` component: ธีมมืด / ธีมสว่าง / ตามระบบ.
- **Providers:** `src/app/providers.tsx` (`'use client'`) — `ThemeProvider` + `QueryClientProvider` (+ HeroUI provider if v3 needs one). Root `layout.tsx` renders it.
- **Utils:** `src/lib/utils/cn.ts` (`clsx` + `tailwind-merge`). `src/lib/utils/format.ts` — `formatTHB(decimalString)` via `Intl.NumberFormat('th-TH', { style: 'currency', currency: 'THB' })` (DR-002 #11: display only, no math).
- **API layer:** `src/lib/api/client.ts` — `apiFetch<T>(path, schema, init?)`: base URL from `NEXT_PUBLIC_API_URL` (default `http://localhost:3001/api`), `credentials: 'include'`, non-2xx → `ApiError` (`src/lib/api/errors.ts`, has `status` + body), 2xx → `schema.parse(json)`. `src/lib/api/menu.ts` — `getMenuItems()` using a **local** Zod schema (moves to `@bar/contracts` when the menu brief lands, DR-004).
- **Mocks:** MSW 2 — `src/mocks/handlers.ts` (`GET */api/menu/items` → 4 Thai sample items incl. one unavailable), `src/mocks/browser.ts`, `src/mocks/node.ts`. Browser worker starts only when `NEXT_PUBLIC_API_MOCKING=enabled` (dev), never in production builds. `public/mockServiceWorker.js` generated by `msw init`.
- **Routes (plain segments, no route groups needed yet):**
  - `/` → redirects to `/pos/menu`.
  - `src/app/pos/layout.tsx` — POS shell placeholder: top bar (venue name + `ThemeToggle`) + left sidebar with one item "เมนู / สต็อก" (Lucide icon). Desktop-first per `pos-desktop.md`.
  - `src/app/pos/menu/page.tsx` + `_components/MenuList.tsx`, `MenuItemRow.tsx`, `MenuListSkeleton.tsx`, `MenuListError.tsx` — HeroUI table/cards: name, category, `formatTHB(price)`, status chip (พร้อมขาย / หมด). Loading, error (with retry), empty ("ยังไม่มีเมนู") states.
  - `src/app/staff/page.tsx` — placeholder "หน้าพนักงาน — เร็ว ๆ นี้" (proves the second surface route exists).
- **Typed routes (BRIEF-001 audit F2):** `typecheck` script → `next typegen && tsc --noEmit`; root layout back to `LayoutProps<'/'>`; pages/layouts use `PageProps` / `LayoutProps`.
- **Tests:** `vitest.config.ts` (jsdom, `@testing-library/jest-dom` setup, MSW node server in setup). Scripts `test`, `test:watch`, `test:e2e` (Playwright). `playwright.config.ts` — Chromium only, starts `next dev` with mocking enabled.
- `app/frontend/.env.example` — `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_API_MOCKING`.
- Delete Next starter assets (`public/*.svg`, starter `page.tsx` content).

## 3. Contract
- **Mock endpoint shape (local, provisional):** `GET /api/menu/items` → `{ items: [{ id: uuid, name: string, category: string, price: "120.00", isAvailable: boolean }] }`. Money is a decimal **string** (DR-002 #11). The menu brief replaces this with the contracts schema.
- **Env:** `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_API_MOCKING` (`enabled` | unset).

## 4. Acceptance Criteria
- **AC-1** — Given `NEXT_PUBLIC_API_MOCKING=enabled pnpm --filter @bar/frontend dev`, when I open `/`, then I land on `/pos/menu` and see 4 items with Thai names, prices formatted like `฿120.00`, and one item with the "หมด" chip.
- **AC-2** — Given the mock returns 500, the page shows the error state with a working "ลองอีกครั้ง" retry; given an empty list, "ยังไม่มีเมนู".
- **AC-3** — `ThemeToggle` switches dark ↔ light ↔ system; the choice survives reload; no wrong-theme flash on first load (dark default).
- **AC-4** — Colors come only from tokens: no hex values in `src/**/*.tsx`, no `dark:` color utilities.
- **AC-5** — `apiFetch` unit tests: non-2xx → `ApiError` with status; invalid body → Zod error; valid → parsed data; `credentials: 'include'` is sent.
- **AC-6** — `formatTHB('1234.50')` → `฿1,234.50` (unit test).
- **AC-7** — `MenuList` component test (MSW node) covers loaded / error / empty.
- **AC-8** — Playwright smoke: `/pos/menu` shows the heading "เมนู" and 4 rows.
- **AC-9** — `typecheck` runs `next typegen && tsc --noEmit` and passes on a clean checkout (no `.next`); root layout uses `LayoutProps`.
- **AC-10** — `pnpm --filter @bar/frontend lint | typecheck | test | build` exit 0; `ci` green; `pnpm install --frozen-lockfile` passes (pnpm 10.x); production build contains no MSW worker registration.
- **AC-11** — Component limits from `frontend.md` hold (≤ 150 lines/component, ≤ 100 lines/page, ≤ 40 lines JSX per component).

## 6. Constraints
- **DR-002 overrides `frontend.md`** on: component library (HeroUI allowed; wrap only a component+config used 2+ times), PWA (removed), dark mode (`next-themes`, tokens), `middleware.ts` → `proxy.ts`. Everything else in `frontend.md` applies (named exports, `'use client'` only when needed, React Query for server state, `lib/api/` wrappers, no axios, hardcoded Thai, `_components/` co-location, size limits).
- **Pattern-setting brief:** every later screen copies the `apiFetch` → React Query → component + states pattern from `/pos/menu`, so keep it plain and readable — it doubles as the reference เมธี learns from. The handoff includes a short "How the data flows" section (MSW → `apiFetch` → React Query → `MenuList`).
- **HeroUI spike rule:** if a HeroUI v3 component needed here doesn't work with Next 16 / React 19 / Tailwind v4 (SSR errors, theming can't take our tokens), stop that part and raise a DR with what failed — that's the point of the spike.
- **Lockfile & parallel work:** BRIEF-004 also changes `pnpm-lock.yaml`. Whichever PR merges second: `git merge origin/main`, then `git checkout origin/main -- pnpm-lock.yaml && pnpm install`, commit the lockfile. Routine — no DR.
- Do not touch `app/backend/**`, `app/packages/**`, `infra/**`, `.github/**`, `turbo.json`.
